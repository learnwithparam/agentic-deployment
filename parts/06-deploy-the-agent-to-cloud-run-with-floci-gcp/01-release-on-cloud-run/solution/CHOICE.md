# When is Cloud Run the better choice?

Cloud Run is better when many people ship the desk. The platform keeps every revision and holds the key.
Compose with my own scripts is better when one machine is enough.

What the emulator does not do: it cannot mount a secret as a file, so the key goes in as a plain value here.
It also saves a traffic setting but does not use it. So I roll back by patching the old template. That makes
a new revision.
