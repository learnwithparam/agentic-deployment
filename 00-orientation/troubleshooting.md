# Troubleshooting

This page lists every message the course's commands print when something is wrong. For each message, it
says what the message means and what to do.

Find the message you see in the first column. For example, if `bun run setup` prints `Docker is not running.`,
start Docker and run `bun run setup` again.

| What you see                                                                       | What it means                                                                                           | Fix                                                                                                                                                                   |
| ---------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `Docker is not running.`                                                           | `bun run setup` could not reach Docker.                                                                 | Start Docker Desktop. On Linux, run `sudo systemctl start docker`. Then run `bun run setup` again.                                                                    |
| `Docker can use only N GB.`                                                        | Docker has less than 4 GB of memory.                                                                    | In Docker Desktop, open Settings, then Resources. Set the memory to 4 GB or more.                                                                                     |
| `Docker Compose 2.24 or newer is needed.`                                          | Your Compose is too old to read optional env files.                                                     | Update Docker Desktop, or install the newest Compose plugin.                                                                                                          |
| `ports ... are in use by another program.`                                         | Another program uses a port that the course needs.                                                      | Stop that program. If it is an old copy of this course, run `bun run down all`.                                                                                       |
| `docker compose could not start the world:`                                        | A world container did not build or start. The lines after it are Docker's own words.                    | Run `docker compose -f world/compose.yaml logs` and read the last lines. `429 Too Many Requests` means Docker Hub limits your downloads. Sign in with `docker login`. |
| `The gateway has no admin key. Run bun run world first`                            | The gateway started without `secrets/gateway_admin_key`.                                                | Run `bun run world`. It makes the secrets first, then starts the services.                                                                                            |
| `The world is not running. Start it with: bun run world`                           | `bun run world status` found no services on ports 7001 to 7004.                                         | Run `bun run world`.                                                                                                                                                  |
| `The finished desk did not start:`                                                 | One of the finished system's containers is not healthy.                                                 | `docker compose -f world/finished/compose.yaml ps` shows which one. To read its logs, run `docker compose -f world/finished/compose.yaml logs <service>`.             |
| `Your desk did not start:`                                                         | `bun run up <step-name>` could not build or start your desk.                                            | Read the lines after it. Then run `docker compose -p hdc-desk logs desk`.                                                                                             |
| `compose.yaml in <folder> has no service named "desk" yet.`                        | The starter files of `package-the-agent` have no desk service.                                          | Add it. That is the first task of the step.                                                                                                                           |
| `<folder> has no compose.yaml yet.`                                                | The step folder has no Compose file.                                                                    | Write `compose.yaml` in that step's `problem/` folder, as the step asks.                                                                                              |
| `There is no step called "..."`                                                    | The step name has a typo.                                                                               | The message lists every step. Copy one name from the list.                                                                                                            |
| `Nothing answers on http://localhost:8080`                                         | The finished desk is not running.                                                                       | Run `bun run up finished`.                                                                                                                                            |
| `Nothing answers on http://localhost:3000`                                         | Your desk is not running.                                                                               | Run `bun run up <step-name>`.                                                                                                                                         |
| `The desk answered 4xx without a stream:`                                          | `/v1/runs` answered with plain JSON or an error, not a stream of events.                                | In `package-the-agent`, return `streamSSE(...)`. In other steps, read the JSON it printed.                                                                            |
| `GATEWAY_KEY is empty, so every model call will be refused.`                       | The starter desk found no key in its environment.                                                       | In `package-the-agent`, pass `GATEWAY_KEY: ${GATEWAY_ADMIN_KEY}` as a build argument. In `move-secrets-out`, read the key file.                                       |
| `The desk cannot start: its gateway key file /run/secrets/gateway_key is missing.` | The desk ran without its Compose secret.                                                                | List `gateway_key` under `secrets:` in the desk service. Also declare it at the top level with its `file:`.                                                           |
| `That gateway key is not known.`                                                   | The desk sent a key that the gateway never gave out.                                                    | Use `secrets/desk_gateway_key`. If you deleted Docker volumes, run `bun run world` again. It registers the keys again.                                                |
| `The key "desk" has spent its budget of $2.`                                       | The desk's gateway key used all of its budget.                                                          | `bun run world reset` sets the spend back to zero. In Part 3 you make the desk stop long before this.                                                                 |
| `The gateway kill switch is on.`                                                   | Someone turned off all model calls at the gateway.                                                      | Run `bun run world reset`. It turns model calls back on.                                                                                                              |
| `"..." is not a role. Ask for fast, smart or judge.`                               | The desk asked the gateway for a model name, not a role.                                                | Ask for a role. Only `config/models.ts` names models.                                                                                                                 |
| `ANTHROPIC_API_KEY is not set` (or the OpenRouter or OpenAI name)                  | `LLM_PROVIDER` names a real provider, but there is no key for it.                                       | Put the key in `.env`, or set `LLM_PROVIDER=replay`. After a change, restart the world: `bun run world stop`, then `bun run world`.                                   |
| `LLM_PROVIDER="..." is not one of replay, anthropic, openrouter, openai`           | There is a typo in `.env`.                                                                              | Use one of the four names.                                                                                                                                            |
| `N role(s) failed. Check the key and LLM_PROVIDER in .env.`                        | `bun run models` could not reach a role. The line above it says why.                                    | Fix the key or the provider, and run it again.                                                                                                                        |
| `Chaos runs only with LLM_PROVIDER=replay`                                         | Chaos commands refuse to run with a real provider, so they never spend real money.                      | Set `LLM_PROVIDER=replay` in `.env` and restart the world.                                                                                                            |
| `The run did not stop within 60 seconds.`                                          | `bun run chaos runaway` sent a run to a desk that has no brakes.                                        | This is the problem that Part 3 solves.                                                                                                                               |
| `The desk never wrote a decision, so there was nothing to interrupt.`              | `bun run chaos kill` saw no decision in the register.                                                   | First check that the desk works: `bun run run-application HDC-2026-0142`.                                                                                             |
| `No rollback within 3 minutes`                                                     | `bun run chaos bad-canary` saw no automatic rollback.                                                   | Open http://localhost:9090/alerts and http://localhost:7010/state. They show where the chain stopped.                                                                 |
| `Send OTLP as JSON` (HTTP 415 from the trace desk)                                 | Your exporter sends protobuf, a binary format. The trace desk reads only JSON.                          | Use `@opentelemetry/exporter-trace-otlp-http`, which sends JSON.                                                                                                      |
| `That username and password do not match.`                                         | The username or password on the council's sign-in page is wrong.                                        | The passwords are in `secrets/passwords`.                                                                                                                             |
| `redirect_uri must be http://localhost:<port>/staff/callback`                      | The desk sent a callback address that the sign-in service does not allow.                               | Use `PUBLIC_URL` plus `/staff/callback`.                                                                                                                              |
| `Sign-in failed. Try again from /staff.`                                           | The desk could not swap the code for a token.                                                           | A code works only once, so start again from `/staff`. Check that `secrets/desk_client_secret` is mounted.                                                             |
| `Public client is not allowed to exchange token`                                   | The desk used the browser client for token exchange. Keycloak allows it only for a confidential client. | Exchange with `permit-desk-server` and its secret from `secrets/desk_client_secret`.                                                                                  |
| `Requested audience not available: permit-service`                                 | The signed-in user has no role on the client they asked a token for.                                    | Give the user a client role on `permit-service` in the realm file. Then restart Keycloak with `docker compose down -v`.                                               |
| `the realm showed no sign-in form`                                                 | Keycloak was not ready, or the client's redirect address does not match.                                | Wait for `docker compose ps` to show `healthy`. The client allows only `http://localhost:3000/staff/callback`.                                                        |
| `FAIL ...` then `Try next: ...`                                                    | A rule in `bun run verify` failed.                                                                      | Do what the `Try next` line says. Then run the check again.                                                                                                           |
| `ERROR the check for <step> could not load`                                        | The check file itself did not run.                                                                      | Run `bun install`, then try again. If it still fails, it is a bug in the course. Please report it.                                                                    |
| `The repo does not meet the standard.`                                             | `bun run check` found a broken course rule.                                                             | Each line names the file and the rule.                                                                                                                                |
